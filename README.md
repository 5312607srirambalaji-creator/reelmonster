# Reel Monster Android App 👾

A cute monster that floats on top of Instagram and YouTube and counts every reel you watch.

### Features
- **Level 1 (Manual)**: Tap the monster bubble to increment.
- **Level 2 (Automatic)**: Uses Android Accessibility to count reels/shorts on scroll without user input.
- **Persistent Data**: SharedPreferences keyed by date survive phone restarts.
- **100% Offline & Private**: Zero internet permissions declared or needed.

### Automatic Cloud Build with GitHub Actions
1. Push this entire repo to GitHub.
2. Go to **Actions** tab.
3. Once the build finishes, download the `.apk` from **Artifacts**.
4. Install on your Android phone!
